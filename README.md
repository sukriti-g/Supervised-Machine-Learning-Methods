## Introduction
Machine learning models can be classified into 2 main types - Supervised and Unsupervised Learning.
Supervised Learning has 2 main types of problems, and that is what this repo covers:
1. Regression
   - predicting a number(s) based on certain inputs
2. Classification
   - predicting the class/category based on the inputs
